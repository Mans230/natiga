# 🤖 بوت نتيجة الثانوية العامة (نظام حديث)

بوت تليجرام يبحث في نتيجة الثانوية العامة **برقم الجلوس** أو **بالاسم**، ويعرض:
الاسم، رقم الجلوس، المجموع من 320، النسبة المئوية، وحالة الطالب (ناجح / دور ثان / راسب / غياب).

---

## 📁 ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `bot.py` | كود البوت الرئيسي |
| `search.py` | منطق تحميل البيانات والبحث |
| `results.pkl.gz` | بيانات النتائج (919,396 طالب) — مضغوطة |
| `requirements.txt` | المكتبات المطلوبة |
| `Procfile` | أمر التشغيل لـ Railway |
| `runtime.txt` | إصدار بايثون |

---

## 1️⃣ رفع الملفات على GitHub (من المتصفح — بدون برامج)

1. ادخل على [github.com](https://github.com) وسجّل دخولك.
2. اضغط زر **+** فوق على اليمين ← **New repository**.
3. اكتب اسم المشروع: `thanaweya-bot` — خليه **Private** (مهم: البيانات خاصة بالطلاب) ← اضغط **Create repository**.
4. اضغط على رابط **uploading an existing file**.
5. اسحب كل ملفات المشروع (bot.py و search.py و results.pkl.gz و requirements.txt و Procfile و runtime.txt و .gitignore و README.md) وأفلتها في الصفحة.
6. اضغط زر **Commit changes** الأخضر تحت.

> ✅ ملف البيانات `results.pkl.gz` حجمه 13 ميجا فقط — جيت هاب يقبله من المتصفح بدون مشاكل (الحد 25 ميجا للملف).

---

## 2️⃣ تشغيل البوت على Railway

1. ادخل على [railway.app](https://railway.app) وسجّل دخول بحساب GitHub.
2. اضغط **+ New Project** ← **Deploy from GitHub repo**.
3. اختر المستودع `thanaweya-bot` (لو أول مرة، اضغط **Configure GitHub App** وادّي صلاحية الوصول للمستودع).
4. بعد ما يبدأ النشر، افتح المشروع ← تبويب **Variables** ← اضغط **+ New Variable** وأضِف:

   | الاسم | القيمة |
   |---|---|
   | `BOT_TOKEN` | التوكن اللي خدته من @BotFather |

5. استنى دقيقتين لحد ما يخلص النشر — في تبويب **Deployments** ← **View Logs** لازم تشوف رسالة إن البوت بدأ.
6. افتح تليجرام وابعت `/start` للبوت — أول رسالة ممكن تاخد ثواني لأنه بيحمّل البيانات (919 ألف طالب) مرة واحدة، وبعدها البحث بيكون فوري.

> ⚠️ لو البوت مش بيرد: تأكد من Logs — لو مكتوب `BOT_TOKEN` غير موجود، راجع خطوة المتغيرات.

---

## 💻 تشغيل محليًا (على جهازك)

```bash
pip install -r requirements.txt
set BOT_TOKEN=التوكن_هنا        :: على ويندوز CMD
python bot.py
```
