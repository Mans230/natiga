# 🤖 بوت نتيجة الثانوية العامة (نظام حديث)

بوت تليجرام يبحث في نتيجة الثانوية العامة **برقم الجلوس** أو **بالاسم**، ويعرض:
الاسم، رقم الجلوس، المجموع من 320، النسبة المئوية، وحالة الطالب (ناجح / دور ثان / راسب / غياب).

---

## 📁 ملفات المشروع

| الملف | الوظيفة |
|---|---|
| `bot.py` | كود البوت الرئيسي |
| `search.py` | منطق تحميل البيانات والبحث |
| `results.pkl.gz` | بيانات النتائج (919,396 طالب) — مضغوطة |
| `requirements.txt` | المكتبات المطلوبة |
| `Procfile` | أمر التشغيل لـ Railway |

---
 تليجرام

- ابعت **رقم الجلوس**: `2001970` (أرقام عربية ٢٠٠١٩٧٠ تنفع برضه)
- أو ابعت **اسم الطالب** كاملًا أو جزءًا منه: `احمد محمود السيد`
- لو في أكتر من طالب بنفس الاسم، البوت يبعت كل النتائج (حد أقصى 20).
